# 계룡시 오늘 날씨·기상특보 조회
계룡소방서 현장대응단 업무 참고용. 페이지를 열거나 ‘지금 조회하기’를 누르면 새로 조회합니다. API 키·네이버 계정·GitHub Actions 설정은 필요 없습니다. 화면을 닫으면 감시·알림이 작동하지 않습니다.

## GitHub → Netlify
1. ZIP을 풀어 public, netlify, netlify.toml, README.md를 저장소 최상위에 올립니다. 기존 뉴스 수집 저장소와 혼동하지 않도록 **새 저장소·새 Netlify 프로젝트** 사용을 권합니다.
2. Netlify → Import an existing project → GitHub 저장소 선택.
3. Base directory 비움 / Publish directory public. 빌드 명령은 netlify.toml의 명령을 사용합니다. Hugo는 사용하지 않습니다.
4. 배포 주소를 엽니다. 서버 함수가 함께 배포돼야 하므로 index.html을 PC에서 직접 여는 방법이나 GitHub Pages만으로는 조회가 작동하지 않습니다.

## 동작
- 날씨: Open-Meteo 비상업 공개 API, 계룡시 대표좌표 36.274 / 127.249. 기상청 관측값이 아닌 모델 기반 현재값·예보. 한국시간, 풍속 m/s.
- 특보: 기상청 공개 웹페이지가 이용하는 현재 특보 표를 서버에서 조회해 전국 항목을 수신하고 계룡시·충청남도·전국 탭 및 시도 지도로 관련 명칭 포함 항목을 선별. 별도 보장된 API가 아니므로 원문 구조 변경·접속 제한 시 실패할 수 있습니다. 예비특보 자동 판별과 지역 제외조건 해석은 하지 않습니다. 미검출은 특보 없음 확정이 아닙니다.
- 날씨·특보 실패는 각각 표시하며, 이전 성공 값을 최신처럼 유지하지 않습니다.
- 요약문 복사 및 인쇄/PDF 제공.
- 키 없이 이용하는 데이터 경로를 사용하지만 Netlify 서버 함수·배포에는 계정별 무료 제공량/과금 정책이 적용됩니다. 사용량을 확인하세요. 대규모·상업적 사용은 Open-Meteo 이용조건을 별도 확인하세요.

## 이번 업데이트
- 오늘 00:00~23:00 전체 시간대 날씨, 기온, 강수확률, 강수량, 풍속. 지난 시간도 모델 자료이며 관측 기록이 아닙니다.
- 계룡시 / 충청남도 / 전국 특보 탭, 시도 지도와 지역 선택 목록. 지도 색은 시도 내 관련 특보 종류를 나타내며 시도 전체 발효를 의미하지 않습니다. 중복 종류는 줄무늬, 선택 상태는 검은 테두리입니다.
- 지역명·시군명으로 관련 후보를 선별합니다. 제외지역 문구나 고성·광주처럼 동명이 있는 지역은 정확히 판별하지 않으며 원문 확인이 필요합니다. 해상 특보는 전국 탭에서 확인하세요.
- 대천항 인근 참고용 보령(DT_0025) 기준 7일 조석·물때(7물식), 만조/간조 시각·높이(cm). 대천항 자체 수치가 아니므로 대천항 물때표 외부 링크도 제공합니다. 예보 높이는 수심이 아닙니다.
- 조석 자료는 국립해양조사원 공개 화면의 조회 경로를 사용합니다. 별도 API 키가 필요하지 않지만 공개 화면 변경/장애 시 자동 조회가 실패할 수 있고, 실패 시 공식 페이지 링크를 이용해야 합니다.

## 산불위기경보·특보 색상 업데이트
- 날씨와 기상특보 사이에 산불위기경보 4단계(관심·주의·경계·심각)와 공식 발령표 조회를 추가했습니다. 발령일시·지역·단계를 함께 표시합니다.
- 산림청 공개 발령표 구조를 확인할 수 없거나 접속 제한 시 자동 확인 불가로 표시합니다. 이번 제작 환경에서도 공식 사이트 접속이 제한되어 실시간 경보 수신은 확인하지 못했습니다. 관심 단계를 기본값으로 간주하지 않습니다. 공식 확인 후 수동 기록(이 기기 브라우저 저장)도 가능합니다.
- 지도 범례: 강풍·풍랑·호우·대설·건조·폭염·한파·태풍·해일·황사·기타. 중복 종류는 줄무늬이며 주의보/경보는 클릭 후 목록에서 확인합니다.
- 시도 내 관련 특보 후보를 표시하는 참고 지도입니다. 제외지역·일부 시군·동명지역의 정확한 경계를 표현하지 않으며 해상 항목은 전국 목록에서 확인하세요. 회색은 미검출이고 조회 실패 시 회색 지도와 미확인 안내를 표시합니다.

## 충청남도 화재위험경보 추가
- 화면 순서: 날씨 → 화재위험경보 → 산불위기경보 → 기상특보.
- 충남 현재 단계를 자동 조회하는 공식 API/현황 경로는 확인하지 못했습니다. 자동 조회로 오인하지 않도록 '최근 확인된 발령'을 표시합니다.
- 최초 기록은 2026-11-02 09:00 전국 소방관서 화재위험경보 경계 발령을 인용한 연합뉴스 보도 기준입니다. 전국 발령의 적용 대상에 충청남도가 포함되는 것으로 표시하며, 충남 별도 발령이라고 표기하지 않습니다.
- 원문 https://www.yna.co.kr/view/AKR20261102101400530
- 운영자가 소방청/충남소방본부의 발령·변경·해제 공문을 확인한 후 public/data/fire-alert.json의 stage, area, issuedAt, verifiedDate, basis, sourceUrl, note를 변경해 커밋하면 모든 이용자에게 배포됩니다. stage는 주의/경계/심각/해제이며 확인 전에는 임의로 갱신하지 마세요. issuedAt은 한국시간 시간대(+09:00)를 포함합니다. verifiedDate는 실제 확인일입니다.
- 확인일이 오늘과 다르면 '현재 단계 미확인'을 표시하고 과거 확인 기록으로 구분합니다. '지금 조회하기'는 이 기록을 다시 읽으며 실제 경보 변경·해제를 자동 감지하지 않습니다.

## 산림청 게이지 원본 직접 조회 수정
기존 빈 HTML 발령표 파싱을 제거하고 홈페이지가 실제로 사용하는 JSON 조회 경로로 변경했습니다.
https://www.forest.go.kr/kfsweb/kfi/dummy/dmmyAjax.do?type=fdms_issue&intv=30
phase_F/level_F는 대표 경보수준, list_F의 phase/dtm/dstrt는 지역별 단계·발령일시·지역입니다. list_L은 산사태 자료이므로 사용하지 않습니다.
실제 조회에서 전국 관심, 발령 2026-11-01 09:00을 수신했습니다(제작 당시 확인값, 코드에 고정하지 않음).
화면을 열거나 조회 버튼을 누를 때, 화면이 보이는 동안 5분마다 산불경보를 다시 조회합니다. 원본 시스템의 캐시·갱신주기 때문에 즉시 반영은 보장되지 않습니다. 별도 인증키는 사용하지 않습니다.
이 수정은 위 설명 중 '발령표 구조 확인 불가로 자동 조회 미확인'이라는 이전 버전의 한계를 해소합니다. 다만 원본 장애·접속 제한·응답 형식 변경 시 확인 불가로 표시하며 기본값으로 관심을 표시하지 않습니다.

## 최신 화면 변경
화재위험경보 영역·정적 기록과 조회 코드를 제거했습니다. 산불경보수준은 상단 오른쪽의 작은 정사각형 위젯(PC 176px, 모바일 144px)으로 이동했습니다. 산림청 원본과 유사한 4색 반원 게이지·바늘로 현재 단계를 표시합니다. 게이지에 마우스를 올리면 지역·발령일시·조회시각을 볼 수 있고 클릭하면 산림청 원문이 열립니다. 실패 시 바늘을 숨기고 미확인으로 표시합니다. 페이지 조회 및 활성 화면 5분 갱신은 유지합니다. 이전 버전의 화재위험경보 설명은 더 이상 적용되지 않습니다.
